# Roto

A moodboard where references can be live: videos, websites and runnable components. Runs on your own computer.

## Setup (one time)

Install these free tools:

- [Node.js](https://nodejs.org) 24 or newer
- pnpm: `npm install -g pnpm`
- ffmpeg: `brew install ffmpeg` (Mac)
- [Google Chrome](https://www.google.com/chrome/)

Then in this folder:

```bash
pnpm install
```

## Use

```bash
pnpm dev
```

Open http://localhost:5180. Boards are saved in the `boards/` folder.
